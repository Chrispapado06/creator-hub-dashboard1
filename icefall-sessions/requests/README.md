# Cross-session requests

Need something from an asset you do not own? Write a file here, then **tell the
product owner it exists** — do not assume the other session will notice.

Filename: `NN-<from-session>-<topic>.md`, e.g. `01-operator-content-versioning.md`

Say: what you need, why, the shape you expect, and what is blocked without it.

| Asset | Owner |
|---|---|
| `icefall-supabase/migrations/*` | Session 03 |
| `icefall-shared/money.ts` | Session 03 |
| Design tokens (`index.css`) | Session 01 |
| Trek catalogue (`trekRecords.ts`, `credits.ts`) | Session 02 |
