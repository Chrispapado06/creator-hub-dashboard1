# Destination photographs — copied, not sourced

**These files came from `icefall-web/public/img/peaks/` and
`icefall-web/public/img/treks/`. They were NOT fetched for this app, and they
must not be.**

Session 02 sourced them, and the sourcing is the expensive part. Their pipeline
is where "a name is not a subject" came from: West Highland Way returned a
terrier, Snowman Trek a snowman, Huemul Circuit a deer, Mount Meru a Buddhist
mandala. The survivors were caught by building a contact sheet and looking at
all of them by eye. An automated pass reproduces that failure and nobody checks
it the second time.

## Credits live with the originals

`icefall-web/src/data/peakPhotoCredits.ts` and `trekPhotoCredits.ts`. Every CC BY
and CC BY-SA licence requires the author named wherever the work appears — so a
second, separately-derived credit file is not duplication of convenience, it is a
licensing failure waiting to happen. There is deliberately no credit file here.
